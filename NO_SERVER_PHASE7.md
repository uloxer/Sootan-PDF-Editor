# Standalone inspection and stamps - phase 7

Verified 28 October 2026. Local review checkpoint; no installer replacement, push, or real Data/profile changes.

## Connected contracts

`document-inspect` accepts one selected PDF, session-only sourcePassword and an allowlisted report: page-count, basic-info, document-properties, page-dimensions, form-fields, annotation-info, font-info, security-info, all-info, javascript or verify-pdf. These are eight Analysis maps plus Get ALL Info, JavaScript export and standards verification. Fixed outputs are output.json or inert UTF-8 output.txt; JavaScript is never executed. Get ALL Info and Show JavaScript hooks dispatch through the native adapter; retained server-mode callers remain compatible.

Plain PdfDocumentAnalysis, PdfDocumentInfo and PdfStandards retain existing report fields and VeraPDF algorithms. Get ALL Info includes Metadata, BasicInfo, DocumentInfo, Compliancy, Encryption, Permissions, FormFields, Other and PerPageInfo, with existing optional summary data. Standards verdicts are real: noncompliance is a report result, not a transport failure. Encrypted standards verification is explicitly unsupported; encrypted Get ALL Info retains complete inspection sections and explains unavailable validation in Compliancy.ValidationError instead of inventing a verdict. Local VeraPDF profiles and worker-only disabled external XML DTD/schema/stylesheet access require no network. The legacy Spring facade delegates to the same plain lifecycle service.

Inspection authenticates readable user credentials without requiring owner privileges. Content-exporting all-info/JavaScript require extraction permission; the fixed INSPECTION_ACCESS_DENIED code gives a useful frontend message. Signed read-only inspection is allowed. Report inputs are bounded to100 MiB/10000 pages and output to32 MiB; oversized reports fail rather than truncate JSON. Passwords are not logged. Worker metadata, private read-only input copies, containment, cancellation and fixed output grants retain the existing boundary.

`stamp` retains existing text/date/image/QR placement, selected pages, margins, rotation, color, opacity and date expansion. QR retains its1000-byte UTF-8 guard. Selected bitmap grants use the existing32 MiB/25-million-pixel decoder boundary, no arbitrary filesystem path. The fixed local Noto font mapping uses the six retained faces; Japanese/Korean/Chinese aliases replace legacy references to absent Meiryo/malgun/SimSun files. Fonts embed once per document; capability is advertised only with all required local faces. Mutation owner/signature guards remain, and original input files are unchanged.
