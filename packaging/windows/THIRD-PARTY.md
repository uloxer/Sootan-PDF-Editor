7-Zip and WiX are build-only tools and are not installed with the app. No Ghostscript, unpaper, LibreOffice or antivirus engine is bundled. The installer is unsigned.

## Windows native dependency terms and distribution status

This local-use build is **not cleared for redistribution**. The pinned Tesseract installer is the exact binary provenance (`downloads.json`); its rolling MSYS2 dependency build/source package revisions have not been independently matched. No source offer is made on behalf of the user. Before publishing binaries, match and make available corresponding source/build instructions for the exact GPL/LGPL DLLs, and review all remaining notices. The installer has not been published.

The runtime `notices/` directory includes full Apache, GPL2/3, LGPL2.1/3, GCC runtime exception and native codec licence texts with retrieval URLs and hashes. `helpers/tesseract/notices` preserves the original Tesseract notices; Python wheel `.dist-info` licences and Java `runtime/legal` remain. These texts supplement, rather than replace, the precise build provenance still needed for redistribution.

In the shipped PE dependency closure: libjbig uses GPL2-or-later (https://www.cl.cam.ac.uk/~mgk25/jbigkit/); libiconv uses LGPL2.1-or-later (https://www.gnu.org/software/libiconv/); libintl/gettext and libunistring use LGPL terms (https://www.gnu.org/software/gettext/ and https://www.gnu.org/software/libunistring/); libidn2 uses LGPLv3-or-later (https://www.gnu.org/software/libidn/); libgcc/libstdc++ use GPL3 with GCC runtime exception. MinGW winpthreads, bzip2 and giflib have their own permissive terms (https://www.mingw-w64.org/, https://sourceware.org/bzip2/, https://giflib.sourceforge.net/). DLL names are recorded in sizes.json; the exact installer SHA256 is retained in downloads.json. MSYS2's package/source catalogue is https://packages.msys2.org/ and https://repo.msys2.org/mingw/sources/.
